# Camera Product Page | Helios Pro 4
This is a product page concept for a camera using HTML, CSS, and Javascript. This was orignally for a job I applied to, but I wanted to take the figma design and make it into a learning project. I wanted to mainly focus on HTML and CSS but expose myself to JS. This isn't responsive.

## 📦 Technologies

- `HTML`
- `CSS`
- `JavaScript`

## ✅ Features
Here are some key components of the product page for Helios Pro 4:

- **Tab Switching**: You can toggle between the `Description`, `Reviews`, and `Shipping`.
- **Form Submission**: In the newsletter section, you can submit an email and it goes to the dummy email.
- **Phone and Email**: You can call the dummy number and email the dummy email when clicked.
